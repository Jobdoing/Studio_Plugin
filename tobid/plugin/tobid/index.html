資料現況說明(照實陳述)
  • 資料來源:政府電子採購網 OpenData 雙月批次 XML(官方列表頁),發布延遲約 6–8 週,每筆僅 6 欄。
  • 預算金額:官方 OpenData 不提供(政策選擇)。民間要求開放 API 的提案(data.gov.tw suggests/88841)至今未被接受;國發會工程標案 API 已停止服務申請。
  • 決標資料(award_*.xml):有決標金額(成交價),無預算金額,同樣延遲。
  • 個案連結:官方網站忽略案號參數,OpenData 也無 pkPmsMain,故無有效 permalink。
  • 民間資料:pcc.g0v.ronny.tw(openfunltd 維護)每日爬取、含預算金額與個案頁——但 Cloudflare 僅允許瀏覽器存取,且為非官方爬蟲資料,授權需另行評估。
  • 本外掛的處理:公告已按案號+機關去重(留最新)、類別對映 工程/財物/勞務、artifact 內嵌 schema_version 供平台啟動時驗證。
外掛的邊界(框架安全設計)
  • 本外掛跑在 sandboxed iframe,無法自行連外抓資料——所有資料由平台以唯讀 SQL 供應(allowlist + 列數上限)。
  • 對外開啟由 shell 代理並經確認(反釣魚)。
  • 外掛只有靜態前端,零伺服器端程式。
示範:站內明細 + ?tender= 深連結

⚠ 官方網站會忽略案號參數(readTenderBasic?tenderCaseNo=… 只會回到搜尋首頁)——官方未提供可程式使用的個案連結。此按鈕保留作為 openExternal 能力示範。
