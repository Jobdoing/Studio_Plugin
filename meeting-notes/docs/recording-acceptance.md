# 會議筆記錄音實測

由 Studio 提供 `studio5.jobdoing.cc` 的專用測試案場後進行，不使用南天門等正式資料。測試完由平台刪除專用案場。真實麥克風由使用者本人操作；開發端的虛擬音源檢查不能代替這項實測。

1. 開啟測試案場的「會議筆記 0.3.0」，同意錄音與文件讀取權限。填寫測試會議名稱。
2. 按「開始錄音」，確認出現 Studio 錄音視窗。先按取消，應回到外掛並可再次開始；此時不應留下音檔。
3. 再開始並允許麥克風，說：「我提議星期五施工，但驗收還沒通過，目前沒有決議。」有第二人時，再說：「我不同意，先完成驗收再討論日期。」確認計時增加，按「停止並儲存」。
4. 確認回到外掛後可試聽，聲音清楚、前後沒有明顯缺失。檢查瀏覽器麥克風使用指示已結束。按「下載錄音備份」確認能開啟；文件中心的會議筆記資料夾應保留原始音檔。
5. 後端與模型設定完成後，按「開始轉錄」→「整理全文」→「產生會議摘要」。全文應保留條件與反對；摘要不能把「提議星期五」寫成「已決議星期五」。兩人實測時，核對說話者有沒有分開；不要求零錯字。
6. 儲存、關閉再重開，確認全文與摘要仍在。若任何步驟失敗，回報停在哪一步與畫面訊息；不要貼金鑰或實際會議內容。

只有錄音、試聽、下載成功，不能宣稱 Azure 辨識與全文／摘要也完成。Safari、手機及連續 2 小時仍是尚未實測項目。
